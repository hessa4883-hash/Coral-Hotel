# 🏨 موقع فندق كورال السودان المتكامل (Coral Hotels Sudan)

موقع ويب فندقي فاخر ومتكامل مصمم خصيصاً لسلسلة **فنادق كورال** في السودان بفروعها في الولايات:
1. **ولاية البحر الأحمر (بورتسودان)**
2. **ولاية كسلا (عروس الشرق - جبال التوتيل)**
3. **ولاية نهر النيل (عطبرة والدامر)**

---

## 🌟 مميزات النظام والموقع

### 1. شاشة النزيل التفاعلية (`index.html`):
- **تصميم فندقي ملكي 5 نجوم** باللونين الكحلي الملكي والذهبي الفندقي مع خطوط عربية فاخرة (Cairo & Tajawal).
- **عرض العروض الترويجية الحصرية** مع نسب الخصم (تصل إلى 33%) والباقات السياحية.
- **عرض الفروع في الولايات الثلاث** مع تفاصيل ومميزات وصور كل فرع.
- **محرك بحث وتصفية متقدم للغرف** حسب الفرع، التواريخ، ونوع الإقامة (أجنحة، ديلوكس، فلل كسلا، شاليهات النيل).
- **بوابة حجز متدرجة تفاعلية (3 خطوات)**:
  1. إدخال بيانات النزيل وتواريخ الوصول والمغادرة وحساب الليالي آلياً.
  2. **الدفع من داخل الموقع**:
     - تطبيق **بنكك (Bankak - بنك الخرطوم)** مع رقم الحساب الرسمي وتفاصيل التحويل الفوري.
     - **بطاقات فيزا / ماستركارد** الائتمانية مع التحقق المصرفي المباشر.
  3. **تأكيد الحجز الفوري وسند الإقامة**:
     - توليد كود حجز فريد (`CR-XXXXXX`).
     - إشعار بمحاكاة رسالة تأكيد نصية (SMS / واتساب) مرسلة لرقم هاتف النزيل.
     - سند حجز وفاتورة رسمية كاملة قابلة للطباعة والتحميل.

### 2. شاشة مدير النظام (`admin.html`):
- **مؤشرات أداء حية (KPIs)**: إجمالي الحجوزات، إجمالي الإيرادات بجنيه سوداني، النزلاء المقيمون، ونسبة الإشغال العام.
- **سجل النشاطات الحية (Real-time Activity Stream)**: رصد لحظي لكل عملية حجز، دفع إلكتروني، أو تحديث.
- **متابعة إشغال فروع الولايات**: شريط قياس ومؤشر إشغال لكل فرع من الفروع الثلاثة.
- **جدول إدارة الحجوزات الشامل**:
  - فلترة الحجوزات حسب الولاية والفرع.
  - فلترة الحجوزات حسب الحالة (مؤكد، تم تسجيل الوصول Check-in، غادر Check-out، ملغي).
  - بحث فوري بالاسم أو رقم الحجز.
  - إمكانية تعديل حالة الحجز فورياً.
  - نافذة عرض تفاصيل النزيل والفاتورة كاملة.

### 3. بوابة النزيل المستقلة (`guest-portal.html`):
- تتيح للنزيل الاستعلام عن حجزه في أي وقت برقم المرجع وهاتفه.
- إمكانية طباعة سند الحجز الرسمي.

## 💾 الربط مع تطبيق XAMPP وقاعدة بيانات MySQL

المشروع مبني بنمط **المحرك الهجين (Dual-Mode Engine)**:
- يعمل **100% بدون خادم** عند رفعه على GitHub Pages عبر التخزين الذكي (LocalStorage).
- يعمل **مباشرة مع قاعدة بيانات MySQL و PHP** عند تشغيله داخل تطبيق XAMPP!

### خطوات التشغيل في XAMPP:
1. تأكد من نسخ مجلد `coral-hotel` إلى مسار:
   ```
   C:\xampp\htdocs\coral-hotel
   ```
   *(تم نسخه وتجهيزه بالفعل).*
2. افتح لوحة تحكم **XAMPP Control Panel** واضغط **Start** لكل من **Apache** و **MySQL**.
3. قم بتهيئة قاعدة البيانات بإحدى الطريقتين:
   - **الطريقة الأسهل**: افتح المتصفح وادخل على الرابط:
     ```
     http://localhost/coral-hotel/api/setup_db.php
     ```
     ثم اضغط على زر **"إنشاء قاعدة البيانات الآن"**، وسيتم استيراد الجداول والبيانات فورياً!
   - **أو عبر phpMyAdmin**: افتح `http://localhost/phpmyadmin`، وأنشئ قاعدة بيانات باسم `coral_hotel` ثم استورد ملف `coral_hotel.sql`.
4. افتح الموقع عبر المتصفح:
   - شاشة النزيل: `http://localhost/coral-hotel/`
   - لوحة تحكم المدير: `http://localhost/coral-hotel/admin.html`
   - بوابة النزيل: `http://localhost/coral-hotel/guest-portal.html`

## 🚀 كيفية الرفع إلى GitHub وتشغيل الرابط (GitHub Pages)

لرفع الموقع وتشغيل الرابط المباشر على الإنترنت:

### الطريقة السريعة:
1. افتح حسابك على [GitHub](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم: `coral-hotel` واجعله **Public**.
2. انسخ رابط المستودع الخاص بك (مثل: `https://github.com/YourUsername/coral-hotel.git`).
3. افتح PowerShell في مجلد المشروع ونفذ:
   ```powershell
   git remote add origin https://github.com/YourUsername/coral-hotel.git
   git branch -M main
   git push -u origin main
   ```
4. **تفعيل الرابط المباشر (GitHub Pages)**:
   - في صفحة المستودع على GitHub، اضغط على **Settings** > **Pages** (من القائمة الجانبية).
   - تحت **Build and deployment**، اختر الفرع **main** ومجلد **/(root)**، ثم اضغط **Save**.
   - خلال دقيقة واحدة سيعطيك GitHub رابط موقعك المباشر المنشور:
     ```
     https://YourUsername.github.io/coral-hotel/
     ```
